The unit suite asserts the count rather than the absence alone, because "no
rowers" and "one character" are two different claims and only the second is the
criterion. `frontend/tests/nodeCrew.spec.ts`:

  - "leaves no rower, oar or hull behind - replaced, not duplicated (T2.9)"
    asserts the rendered HTML of a running card contains none of
    `node-crew`, `node-rower`, `node-oar`, `node-hull`.
  - "mounts exactly ONE character, inside the workflow node" asserts
    `wrapper.findAll('.pip')` has length 1, and that it is found by
    `.workflow-node .pip` and by `.node-character .pip` — the two selectors
    `e2e/cast.spec.ts` uses.
  - "is on an agent card in EVERY state, not only while it runs" is the claim
    the boat could not make: the crew appeared on `running` and nowhere else,
    so for most of a run it said nothing.
  - "gives no character to a router, gate, output or step" pins the other half:
    those four keep their lucide medallion and get no face, because a router
    makes no model call and a gate is a person being asked for something.
